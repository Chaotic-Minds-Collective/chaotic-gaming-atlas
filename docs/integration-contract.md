# ATLAS Integration Contract

Translate verified server observations into platform events and status updates. Core remains authoritative for Chaotic Minds Gaming accounts, permissions and entitlements. Preserve source identifiers as strings and retain cluster/grid/server context; character, tribe and transfer identifiers are not assumed to be one-to-one.

Before implementation, record exact server build, plugin API version, callbacks, threading model, config format and failure behavior from a reproducible isolated test.
