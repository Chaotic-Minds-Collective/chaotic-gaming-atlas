# ATLAS Plugin Roadmap

The initial implementation order is server health, audit logging, announcements, sessions/statistics, permissions and admin tooling. Before code depends on Atlas Server API 1.71, prove the loader against the exact target server build in an isolated environment. See the central [plugin catalogue](https://github.com/Chaotic-Minds-Collective/chaotic-gaming-docs/blob/main/plugins/PLUGIN_CATALOG.md).
